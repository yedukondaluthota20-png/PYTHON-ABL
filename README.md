# Python ABL Case Studies

This repository contains the README for a set of Python business-logic case studies described in the accompanying **PYTHON ABL** assignment. Each case presents a practical problem, its assumptions, an algorithm, pseudocode, sample Python code, a test case, and a short conclusion.

## Case studies

1. University scholarship allocation
2. Progressive electricity billing
3. Hospital billing and patient classification
4. Employee payroll and deduction analysis
5. Multi-plan telecommunications cost optimization
6. Railway fare and reservation calculator
7. Retail billing with multiple discount rules
8. Manufacturing cost and profitability analysis
9. Multi-currency travel budget analysis
10. Campus event financial planning

## Topics covered

The examples practice input validation, conditionals, loops, lists, sorting, arithmetic, slab and progressive calculations, discounts, taxes, fees, eligibility filtering, ranking, and formatted output. They use standard Python and are intended for learning and adaptation.

## Running the examples

The assignment document contains the code examples; this workspace does not currently include separate Python source files. To run an example, copy its **Python Code** section from the assignment into a `.py` file, then run it with Python 3:

```bash
python case1_scholarship.py
```

Each program prompts for its input interactively. Use the matching test case in the assignment to check the expected behavior. Filenames above are examples; create the file before running the command.

## Notes

- Values such as currency units, eligibility thresholds, rates, and fees follow the assumptions stated in each case.
- These are educational examples, not production billing, payroll, medical, or financial systems.
- Review each case's assumptions and validation rules before adapting its code.
